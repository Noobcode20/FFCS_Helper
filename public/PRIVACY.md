# Privacy

Your imported catalog, saved plans, blocked times, and preferences are processed in this browser and stored in this browser's local storage. They are not uploaded by the app. There is no account, cloud sync, analytics, advertising, or VTOP connection in the public planner. Import, export, and backup actions are initiated by you in the browser.

The app is served as static files. As with any website, the hosting provider and network may receive ordinary request metadata such as your IP address, requested file paths, and user agent. Hosting and network logs are outside the app's local-only storage guarantee. The app's Content Security Policy blocks fetch, WebSocket and beacon connections; imported schedules cannot be sent to a third-party endpoint by app code under that policy.

Do not include personal identifiers in public catalog data or submit a plan backup to a public repository. Browser storage is not encrypted; anyone with access to your browser profile can access its contents. Clearing site data removes locally stored plans and imports.

The checked-in catalog and VTOP allocation data are public static source data. They must not contain account usernames or student IDs. See [Data sources](./DATA_SOURCES.md) for provenance and limits.
